# 🚀 LeetCode DSA Solutions

Welcome to my **LeetCode DSA repository**!

This repository contains my solutions to **Data Structures and Algorithms (DSA)** problems solved on [LeetCode](https://leetcode.com/).

The solutions are automatically synced to this repository using **LeetSync**, so whenever I submit a solution on LeetCode, the corresponding solution is pushed to GitHub.

## 📌 About

I am using this repository to:

* 🧠 Improve my problem-solving and DSA skills
* 💻 Practice coding consistently
* 📚 Maintain a collection of solved LeetCode problems
* 🔍 Review different algorithms and approaches
* 📈 Track my progress over time
* 🚀 Prepare for technical interviews and placements

## 🛠️ Languages

Solutions may be written in:

* C++


## 📂 Repository Structure

Problems are organized according to the structure generated by LeetSync.

```text
LeetCode-DSA/
│
├── 0001-two-sum/

├── 0121-best-time-to-buy-and-sell-stock/

├── ...
│
└── README.md
```

Each problem contains its corresponding solution and Problem Description as README file .



## 🔄 Automatic Sync

This repository is connected to **LeetSync**.

### Workflow

```text
Solve Problem on LeetCode
          ↓
      Submit
          ↓
     Accepted ✅
          ↓
       LeetSync
          ↓
   GitHub Repository
```

This allows me to focus on solving problems without manually copying and pushing every solution.
